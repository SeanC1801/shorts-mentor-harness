# Short Storyboard
Read episode state, approved concept, standards, checklist, contracts, and storytelling guide. First run `python3 tools/approval_state.py sync EPISODES/<ID>` and stop if the idea gate is not currently approved. If idea approval is absent or invalidated, stop. Research each claim and cite source title, publisher, URL, access date, and support/limits; separate fact, interpretation, and hypothetical. Draft concise English narration in the channel's own voice (`channel-identity.md`; reference-channel patterns in `02_CONTEXT/source-analysis/channel-reference-notes.md` are hypotheses, not a style to imitate) in the creator's story-chain format (see `storytelling-guide.md` "Script format" and `source-analysis/narration-style-notes-story-chain.md`, plus `me.md` and `narration-style-notes*.md`; craft only, never imitate a voice or copy wording): one continuous paragraph with a premise-with-a-purpose opening that withholds the outcome, one line of context, setup and rule, a short-sentence trigger, escalation, one reversal, a late reveal, and a closing callback to the title. If the approved concept card says the episode carries a format test (`03_TRACKING/format-tests.md`), apply the tested change in place of the matching rule and say so in the script notes. Run the story-chain check from the guide, present the narration with a beat map, and keep visual explanation, emotional/pacing beats and the payoff in the beat map. Present script version for explicit approval; stop until approved. Record the creator’s explicit approval with `approval_state.py record --gate script` before continuing. Then sync timing to measured ElevenLabs audio when available. Build storyboard and `episode.json` using integer 30fps frames (motion rules v3), half-open contiguous ranges, audio ranges, character, pose and face (from `character-registry.md`; a character on screen in most shots), 2-3 camera views per line with how each joins the next (follow, push-through, whip or dissolve), lighting state, captions, SFX/music, transitions, and asset IDs. Validate against schema and cross-field timing; if narration audio is unavailable, label timing provisional. Run `python3 tools/validate_episode.py EPISODES/<ID>` and fix errors. Present storyboard for separate explicit approval; record only after the creator approves the exact version using `approval_state.py record --gate storyboard`. Changes invalidate downstream gates.
