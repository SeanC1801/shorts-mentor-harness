# Short Storyboard
Read episode state, approved concept, standards, checklist, contracts, and storytelling guide. First run `python3 tools/approval_state.py sync EPISODES/<ID>` and stop if the idea gate is not currently approved. If idea approval is absent or invalidated, stop. Research each claim and cite source title, publisher, URL, access date, and support/limits; separate fact, interpretation, and hypothetical. Draft concise English narration in the channel's own voice (`channel-identity.md`; reference-channel patterns in `02_CONTEXT/source-analysis/channel-reference-notes.md` are hypotheses, not a style to imitate) with an anti-hook opening (see `me.md`, `storytelling-guide.md`, and `source-analysis/narration-style-notes.md`; craft only, never imitate a voice), gradual context, emotional/pacing beats, visual explanation, and payoff. Present script version for explicit approval; stop until approved. Record the creator’s explicit approval with `approval_state.py record --gate script` before continuing. Then sync timing to measured ElevenLabs audio when available. Build storyboard and `episode.json` using integer 24fps frames, half-open contiguous ranges, audio ranges, character/pose, camera, captions, SFX/music, transitions, and asset IDs. Validate against schema and cross-field timing; if narration audio is unavailable, label timing provisional. Run `python3 tools/validate_episode.py EPISODES/<ID>` and fix errors. Present storyboard for separate explicit approval; record only after the creator approves the exact version using `approval_state.py record --gate storyboard`. Changes invalidate downstream gates.
