# Short Ideate
Read `me.md`, routing, mentor protocol, production standards, and channel identity. If the creator has not supplied an original seed, request it and stop. Preserve the seed verbatim. Develop up to three framings derived from it; show central question, hook promise, audience assumption, emotional shape, visual opportunity, payoff, research path, and risks. Cite any factual claims. For framing ideas, you may use the question patterns in `02_CONTEXT/source-analysis/channel-reference-notes.md` as prompts only; never copy a reference title, premise, or voice. Mentor critiques both concept and storytelling without imitating the transcript creator. Present a versioned concept card and ask for explicit approval/revision. Stop; do not script or advance state without approval. After explicit creator approval, run the documented `approval_state.py record` command for the exact displayed version and record the decision in episode files. Never record approval for ambiguous assent.
